# Word acceptance fixtures

Use real Microsoft Word documents to exercise the MVP. The full fixture pack will be expanded after the first Windows Word acceptance run.

Recommended files:

1. `01-normal.docx` — TVCI-default paragraph formatting.
2. `02-wrong-font.docx` — one paragraph in Arial.
3. `03-wrong-margin.docx` — reserved for page-rule milestone.
4. `04-wrong-paragraph.docx` — wrong alignment/spacing.
5. `05-tables.docx` — verifies MVP does not blanket-format tables.
6. `06-header-footer.docx` — verifies selection scope does not alter header/footer.
7. `07-template-content-control.docx` — can start from `../templates/sample-template.docx`.
8. `08-long-document.docx` — performance regression fixture.
